# AI 답변 적용 예시와 과잉 교정 방지

아래 예시는 책의 교정 관점을 적용해 새로 작성했다. 책의 원문 예시가 아니다. ‘교정 후’는 가능한 수정안이며 동일한 문구를 재현할 필요는 없다.

## 답변을 다듬는 예시

| 초안 | 교정 후 | 판단 |
|---|---|---|
| 이 기능에 대한 설명을 제공하도록 하겠습니다. | 이 기능을 설명하겠습니다. | 목적어와 동사를 직접 연결한다. 계획 시제는 유지한다. |
| 설정의 변경에 있어 주의가 필요한 부분은 경로의 지정입니다. | 설정을 바꿀 때는 경로를 주의해서 지정해야 합니다. | 명사 나열을 행동으로 푼다. |
| 제가 확인한 것은 두 파일의 내용이 동일하다는 것입니다. | 두 파일의 내용이 같다고 확인했습니다. | 확인했다는 근거 수준을 유지하며 명사화를 줄인다. |
| 모든 항목들에 대한 검사를 수행했습니다. | 모든 항목을 검사했습니다. | 복수와 우회적인 동사 표현을 줄인다. |
| 결과가 두 그룹으로 나뉘어져 있습니다. | 결과가 두 그룹으로 나뉘어 있습니다. | 겹친 피동만 줄이고 결과 상태는 남긴다. |
| 담당자가 검색 기능을 개선시키고 있습니다. | 담당자가 검색 기능을 개선하고 있습니다. | 불필요한 사동을 줄이고 진행 상태는 남긴다. |
| 제가 빠르게 오류 메시지를 다시 읽은 뒤 설정을 수정했습니다. | 제가 오류 메시지를 다시 읽은 뒤 설정을 빠르게 수정했습니다. | ‘빠르게’가 수정 동작을 꾸민다는 문맥일 때만 옮긴다. 원문만으로 뜻을 확정하지 않는다. |
| 오류 메시지와 설정 파일을 수정했습니다. | 오류 메시지를 확인하고 설정 파일을 수정했습니다. | 문맥상 메시지는 읽기만 했다는 사실이 확인된 경우에만 고친다. 둘 다 수정했다면 원문을 유지한다. |
| 조사에서 기능을 사용하는 사람이 30%였습니다. | 조사 응답자 가운데 이 기능을 사용하는 사람은 30%였습니다. | 분모가 조사 응답자라는 근거가 있을 때 기준 집단을 명시한다. |
| 실패할 수 있는 가능성이 있습니다. | 실패할 가능성이 있습니다. | 중복만 줄이고 가능성은 유지한다. |
| 성공 여부에 대한 확인이 필요합니다. | 성공했는지 확인해야 합니다. | 막연한 명사 연결을 간접 의문으로 푼다. |
| 저장이 완료되셨습니다. | 저장이 완료되었습니다. | 저장 동작에 붙은 높임을 바로잡는다. |

## 그대로 남겨야 하는 사례

| 문장 | 보존해야 할 정보 |
|---|---|
| 아직 검증하지 않아 이 설정으로 오류가 해결될지는 확실하지 않습니다. | 미검증과 불확실성. ‘이 설정으로 오류가 해결됩니다’로 바꾸지 않는다. |
| 이 명령을 실행하면 파일이 삭제될 수 있습니다. | 조건과 가능성. 삭제된다는 단정이나 실행했다는 보고로 바꾸지 않는다. |
| 사용자는 파일을 내려받을 수 있습니다. | 기능·권한. 실제로 내려받았다는 뜻이 아니다. |
| 파일을 저장하고 있습니다. | 진행 중인 상태. ‘저장했습니다’는 완료 여부를 바꾼다. |
| 파일이 삭제되었습니다. 원인은 아직 확인하지 못했습니다. | 행위자 미상. ‘제가 파일을 삭제했습니다’처럼 주체를 만들지 않는다. |
| 예전에 사용했던 계정으로는 로그인하지 못했습니다. | 회상·과거 사용 이력과 부정. 자동으로 현재 계정처럼 바꾸지 않는다. |
| 백업을 시작했습니다. | 개시. ‘백업했습니다’로 줄이면 완료를 암시한다. |
| 여러 대안 중 하나입니다. | 다른 대안도 존재한다는 범위. ‘유일한 대안’이나 ‘최선의 대안’으로 바꾸지 않는다. |
| 통계적 유의성과 실용적 가치는 다릅니다. | 용어의 뜻. ‘-적’을 일괄 삭제하지 않는다. |
| 검토는 했지만 수정하지는 않았습니다. | 대조와 수행 범위. ‘검토하고 수정했습니다’로 바꾸지 않는다. |
| 버튼을 누르면 창이 열립니다. 다만 권한이 없으면 오류가 표시됩니다. | 조건과 예외. 접속어와 예외 절을 남긴다. |

## 문단 적용

초안:

> 현재의 구현에 있어 제가 수행한 것은 설정 파일에 대한 수정입니다. 이 수정으로 인해 오류가 해결될 수 있을 것으로 보이지만, 실제적인 실행에 대한 검증은 아직 수행하지 않은 상태입니다. 따라서 지금의 단계에서 성공 여부에 대한 확정적인 판단을 내리는 것은 어렵습니다.

교정 후:

> 설정 파일을 수정했습니다. 오류가 해결될 가능성이 있어 보이지만, 아직 실제 실행 결과를 검증하지는 않았습니다. 따라서 성공 여부는 확정하기 어렵습니다.

수정한 대상, 해결에 대한 추정, 실행 검증을 아직 하지 않았다는 사실, 판단의 한계를 유지한다. ‘오류를 해결했습니다’로 줄이면 의미가 달라진다.

## 사용자가 교정 설명을 요청한 경우

전후 문장과 핵심 이유를 필요한 만큼 제시한다. 일반적인 답변 생성에서는 위 표나 교정 과정을 덧붙이지 않고 다듬은 답변만 출력한다. 원문이 이미 자연스러우면 바꿀 필요가 없다.
